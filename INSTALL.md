# dsh-redstone-close 1.0.0

Minecraft material close button for DeepSeek Harness.

## Install

1. Unzip dsh-redstone-close-1.0.0.zip.
2. In DeepSeek Harness, open **Plugins -> Add plugin**.
3. Choose the extracted dsh-redstone-close-1.0.0 folder (the folder containing package.json).
4. The plugin is enabled immediately; if the button does not appear, reload the page with F5.

The .tgz is the npm-format source package for archival/alternative package-manager use.
