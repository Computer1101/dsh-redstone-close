# Minecraft 材质关闭按钮

一个 DeepSeek Harness 界面插件，在右上角放一个 Minecraft 风格的像素材质图标按钮。
默认为草方块，可在设置中切换草方块、红石、青金石、钻石、下界合金锭、铁锭、金锭、
绿宝石；每种材质会改变按钮/特效图标、主题颜色与专属音效。单击后播放图腾式爆发
特效与 Minecraft 原版音效，整套动画约 4.5 秒，结束时会请求正常关闭 Harness 窗口。

## 安装

这是 DeepSeek Harness 桌面端 bundle。在 Harness 中打开 **插件 → 添加插件**，
选择本文件夹（或解压安装包后选择解压出来的文件夹）。安装后立即启用，通常无需
重启。插件使用 Harness 的 `shortcuts.closeWindow()` 桌面关闭桥，因此面向桌面端，
不是浏览器里的 Harness 页面。

## 点击后发生什么

1. 右上角当前材质的像素按钮脉冲发亮，并播放对应材质的 Minecraft 音效。
2. 屏幕闪白、闪电从按钮位置炸开，符文环与放射光轮旋转成形，中心浮起
   大型像素材质核心，冲击波环与像素碎片向外扩散。
3. 约一千颗余烬、火花、尘埃与碎片向外飞散，配合屏幕震动、连续材质色闪光与结尾
   收缩的材质色光圈。
4. 将所选材质的专属采样与 Minecraft 1.20.1 原版 TNT、发射器、活塞采样混合，
   编排在 4.5 秒内。
5. 约 4.5 秒时调用 Harness 自带的 `shortcuts.closeWindow()` 服务关闭当前聚焦窗口，
   与原本的“关闭到托盘”行为一致。随后界面会复位，从托盘重新打开时不会残留黑屏
   或隐藏按钮。

## 性能设计

- 单张全屏 canvas、单个 `requestAnimationFrame` 循环，逐帧不做对象分配。
- DPR 有上限，canvas 限制在约 320 万设备像素内，高分屏不会浪费填充率。
- 光晕、余烬、冲击波、符文、射线与像素红石核心全部预渲染为离屏精灵，只做绘制；
  径向渐变按窗口尺寸缓存。
- 检测到 `prefers-reduced-motion` 时粒子数量减半，并关闭屏幕震动。
- 卸载时会释放所有计时器、音频播放器、动画帧和注入的样式。

## 关闭失败兜底

`shortcuts.closeWindow()` 使用 Harness 支持的窗口关闭路径，把窗口隐藏到托盘。
如果约 850 毫秒后窗口仍然可见（例如焦点已切到其他应用），插件会复位特效并提示
手动关闭。不使用原生 helper、外部进程或网络端口。

## 设置

在 **设置 → 材质关闭**（或“插件 → 已安装”里打开本插件页面）中，底部有“材质关闭设置”：

- **材质**：草方块 / 红石 / 青金石 / 钻石 / 下界合金锭 / 铁锭 / 金锭 / 绿宝石；改变图标、主题色与专属音效。
- **音效**：是否播放 Minecraft 原版材质、TNT、发射器与活塞采样。
- **特效强度**：全开 / 轻量；轻量会降低粒子数量。
- **结束后关闭窗口**：关闭后只预览特效，不隐藏 Harness 窗口。

设置保存在本机，下一次点击时生效。

## 文件

- `client.js`：界面、canvas 渲染、采样音效、关闭请求。
- `index.js`：刻意留空的 Host 半。
- `cordis.patch.yml`：bundle 插入行。
- `sounds/*.ogg`：Minecraft 1.20.1 原版各材质、点击、活塞、爆炸采样。
- `locale/en.json`、`locale/zh.json`：插件清单标题与描述。
- `icon.png`：36×36 像素草方块图标。
- `assets/grass_block.png`：插件内草方块精灵与图标生成用的高清源图。

## 卸载

通过 DSH 插件管理器移除 `@local/dsh-redstone-close` bundle。插件不会写入自身
包和 profile 正常 bundle 记录以外的内容。
